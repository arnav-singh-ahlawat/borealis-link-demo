# Concordia demo photo sources

The demo uses photographs downloaded from Concordia University's official website on November 19, 2026. Photo source and credit for each image is Concordia University. The source pages and original image URLs are linked below.

`tools/prepare_images.py` resizes and pads each photograph to 192 × 128 pixels, stores a baseline JPEG, and pre-encodes the SSDV packets for transmitter flash.
